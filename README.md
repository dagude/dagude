## Capital & Corporate Practice

**M&A.** Origination, screening and qualification; financial and commercial diligence including quality of earnings; technical and product diligence; valuation through DCF, comparables and transaction multiples; term sheet and structuring; negotiation through LOI and SPA; closing, integration planning and value-creation tracking; exit positioning.

**Investment management.** Private and public assets — fintech and financial infrastructure, listed financials, and public-sector spend flows as an analytical edge. Monitoring is a discipline, not a report: KPIs, unit economics, regulatory posture and product signals tracked continuously, with AI-driven analysis where it adds signal.

**Value-creation stance.** The operating thesis is engineering leverage: margins in fintech come from software, and software leverage only materializes when the operating model, the data and the regulatory surface are understood at the same time.

## Method

- Start with unit economics, not the deck.
- Model the base case and know exactly which assumption breaks it.
- Read the code and the data room — in fintech, the product *is* the diligence.
- Verify the regulatory and compliance posture before modeling anything.
- Build for the operating model: if it cannot be monitored, it cannot be scaled.
